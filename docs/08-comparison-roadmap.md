## 3. MVP 推荐

**MVP = 插件骨架 + 方案六(海龟汤)+ 方案一(侦探推理)。**

理由:

1. **方案六验证骨架**:海龟汤只需要"答案卡封存 + 是/否/无关判定 + 计分",即可走通骨架的每一个组件(GameStateStore、TruthVault、Adjudicator、ScoreService、UI 卡片、checkpoint)。骨架成,则所有方案共享的 80% 工程已就绪。
2. **方案一验证范式与市场**:侦探推理复用了骨架中最重的三件套——**NPC 子代理(审讯)、事实图(真相封存)、推理评分(verifier)**——这三件套也是方案三、五、七的核心依赖。做成侦探,等于给半个产品线铺路。
3. **性价比最高**:两个方案的内容成本都可通过"模板 + 程序化生成 + 求解器验证"控制,不像跑团/剧本杀需要大量人工调优。

## 4. 分阶段路线图

```
阶段 0  插件骨架
        GameStateStore / TruthVault / ActionRegistry / CommandRegistry
        Adjudicator / Verifier / NpcRuntime / HintService / ScoreService
        CheckpointService + UI 卡片 + 结算页
        验收:骨架组件全部有单测;可挂载进 game profile 启动
        ▼
阶段 1  方案六 轻量小游戏(海龟汤 → 卧底 → 20问)
        验收:完整游玩闭环;答案零泄露(压力测试);计分与结算卡片可用
        ▼
阶段 2  方案四 密室逃脱(确定性谜题引擎)
        验收:谜题引擎单测全覆盖;任意动作裁决无幻觉;三层提示系统可用
        ▼
阶段 3  方案一 侦探推理(MVP 目标)
        验收:案件生成器 + 可解性求解器 + 审讯 NPC + 推理报告评分全链路
        至此产品可对外发布第一个正式版本
        ▼
阶段 4  方案三 剧本杀(多智能体旗舰)
        验收:6 角色群戏编排;凶手约束与泄密审计达标;"我是凶手"反转模式可用
        ▼
阶段 5  方案五 时间循环(创新旗舰)
        验收:因果时间表引擎;循环 diff;完美循环验证
        ▼
阶段 6  方案二 单人跑团 / 方案七 王国议会(长线扩展)
        二选一或并行,视用户反馈决定投入
```

每一阶段的退出条件是**上一阶段方案可完整游玩并通过验收**,而非"组件写完"。

> **当前进度(v0.16.0)**:阶段 0 骨架 ✅、阶段 1 海龟汤 ✅(8 题,规则裁决 + LLM 兜底)、阶段 2 密室逃脱 ✅(第七扇门,确定性谜题引擎 + 三层提示 + 暴力猜谜审计 + 程序化题库三皮肤可解性求解器)、阶段 3 侦探推理 ✅(生成器 + 求解器 + 推理评分 + 泄密审计 + NPC 子代理)、阶段 4 剧本杀 ✅(v1 核心闭环 + 反转模式 + 程序化剧本池 + subagent 群戏 fan-out)、阶段 5 时间循环 ✅(v1 确定性内核 + 快进重放 + 3 本手工剧本 + 皮肤变体 M3 + 程序化时间表 M4 + NPC 子代理(循环内失忆))、阶段 6 ✅(方案七 王国议会 v1 + 方案二 单人跑团 v1(程序化世界生成 M2 + NPC 子代理))。**路线图全部阶段达成**。NPC 台词统一走隔离子代理(spawn、无工具、真相不进入 NPC 会话、泄密审计保留),服务缺失时自动回退插件侧 LLM;可选后续演进 = continuable 持久 NPC 会话(跨轮私有记忆)与 workflow 群戏辩论编排。

## 5. 选择首个开发方案时的决策参考

如果不想按上述路线,可按下面三个问题自选:

1. **要最快见到可玩的东西?** → 方案六(小时级)→ 方案四(天级)。
2. **要最能代表"LLM 原生游戏"的作品?** → 方案一(标准答案)→ 方案五(大胆答案)。
3. **要最能炫技多智能体?** → 方案三(剧本杀)。

无论选哪个,**方案六的海龟汤都应作为骨架联调用例先行实现**——它既是产品功能,也是插件管道的冒烟测试。

## 6. 组合风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| LLM 行为漂移:同一天写的案件生成器,下个月模型升级后行为变化 | 内容质量与可解性波动 | 生成后一律过求解器/verifier 验证;golden case 回归测试(固定输入断言可解) |
| 上下文膨胀:长局(NPC 会话 + GM 叙事)吃掉 token | 单局成本与延迟上升 | 分层摘要(NPC 角色档案、GM 日志摘要)、compaction 策略、必要时裁剪真相投影 |
| NPC 泄密/被诱导 | 推理游戏瞬间失去价值 | 真相不进 NPC 上下文;verifier 定期审计;诱导检测(玩家问题命中高危模式时警告) |
| 重复游玩内容枯竭 | 剧本杀/时间循环类重玩价值下降 | 程序化生成优先于手写剧本;模板参数化拉开差异 |
| 平台 API 变更 | 插件失效 | 插件只依赖稳定公开 seam(tools/commands/settings/session 事件),设计期即隔离;随 DSH 版本跟进 |
