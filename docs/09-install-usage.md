# dsh-xgame 安装与使用指南

> 面向玩家的完整手册:安装、开局、七款游戏的玩法与命令、计分、存档、常见问题。
> 插件简介与开发说明见仓库根 [README.md](../README.md);游戏设计文档见 `docs/01`~`08`。

---

## 1. 这是什么

**dsh-xgame** 是 DeepSeek Harness(DSH)的游戏插件:在 DSH 的 Web 聊天界面里,由大模型担任主持人(GM)与 NPC,陪你玩七款文字冒险/推理游戏。

| 游戏 | 类型 | 单局时长 | 一句话 |
|---|---|---|---|
| 海龟汤(`soup`) | 情境推理 | 5-15 分钟 | 主持人只知道"是/否/无关",你用二分问题还原汤底 |
| 侦探推理(`detective`) | 本格推理 | 30-60 分钟 | 勘查现场、审讯会撒谎的嫌疑人、提交推理报告逐条评分 |
| 密室逃脱(`escape`) | 谜题 | 20-45 分钟 | 自然语言操作机关,确定性引擎裁决,LLM 只负责讲故事 |
| 剧本杀(`party`) | 社交推理 | 60-120 分钟 | 5 名 AI 角色同处山庄,搜证对质、公聊群戏、指控凶手;难度 3 = 你当凶手 |
| 时间循环(`loop`) | 推理/叙事 | 60-120 分钟 | 困在重复的一天,用跨循环的知识改写注定发生的悲剧 |
| 王国议会(`council`) | 策略经营 | 数小时(跨会话) | 四名各怀议程的 AI 顾问吵成一团,你拍板,账本替你承担后果 |
| 单人跑团(`trpg`) | 沙盒冒险 | 数小时(跨会话) | 建卡、掷骰、奇招裁决、任务链、程序化世界自由冒险 |

**核心保证**:所有游戏的真相(汤底/案卷/谜底/剧本/时间表/账本)只存在插件引擎里,**永不进入模型上下文**——主持人想剧透也做不到;游戏状态落盘,随时存档续玩。

## 2. 安装

### 2.1 前提

- Node.js ≥ 22,已安装 DSH 命令行:`npm install -g @deepseek-ai/dsh`(装完 `dsh` 可用);
- 一个可用的 LLM API key(DeepSeek 官方 key 或自建网关 key)。

### 2.2 安装插件并创建 game profile

**方式 A:npm 安装(推荐)**

```sh
dsh plugin --profile game add dsh-xgame
```

**方式 B:本地构建安装(开发 / npm 暂不可用时)**

```sh
git clone https://github.com/leo-lab-2026/dsh-xgame.git
cd dsh-xgame
npm install && npm run link-deps && npm run build
dsh plugin --profile game add link:$(pwd)
```

无论哪种方式,确认 `~/.dsh/profiles/game/package.json` 的 bundles 为:

```json
{
  "dependencies": { "dsh-xgame": "..." },
  "dsh": {
    "profile": { "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-xgame"] }
  }
}
```

> 自动初始化的 profile 只有 `@deepseek-ai/dsh-base`;**必须手动补上 `@deepseek-ai/dsh-web-app`** 才有网页界面。

### 2.3 配置 LLM(最容易漏的一步)

编辑 `~/.dsh/settings.yaml` 指定默认 provider/model;key 写入 `~/.dsh/.credentials.yaml`(私密文件,勿提交):

```yaml
# ~/.dsh/settings.yaml
agent-default-model:
  provider: <你的 provider 名>
  model: deepseek-v4-pro
```

```yaml
# ~/.dsh/.credentials.yaml
OPENCODE_GO_API_KEY: sk-你的key
```

provider 写法按你的网关文档;也可以先运行 `dsh web` 走 UI 引导配置模型。

### 2.4 启动

```sh
dsh --profile game --port 3180
```

浏览器打开 http://127.0.0.1:3180,新建会话。两种开局方式等价:

```
/game new soup                  # 斜杠命令开局
"想玩剧本杀"                     # 或直接说,GM 会调用 game_start 工具开局
```

## 3. 通用命令

| 命令 | 用途 |
|---|---|
| `/game new <soup\|detective\|escape\|party\|loop\|council\|trpg> [难度 1-3]` | 开局 |
| `/game resume` | 恢复存档对局 |
| `/game score` | 查看当前得分/进度 |
| `/game quit` | 结束对局并查看完整真相(含结算) |
| `/hint` | 购买一条提示(计入效率分) |

各游戏另有专属面板命令(见 §4)。开局后主持人接管对话——你像聊天一样自由输入即可,不需要背工具名。

## 4. 各游戏指南

### 4.1 海龟汤(`/game new soup [1-3]`)

- **目标**:用最少的"是/否"问题还原汤底(一个反常情境背后的完整真相)。
- **玩法**:主持人给出汤面后,你不断提问("汤里有毒吗?""他以前喝过这个味道吗?")。主持人**不知道汤底**,每个问题都交给引擎裁决(是/否/无关),因此它无法剧透、也答不错。
- **计分**:结论正确性(还原成功 100)+ 效率(问题数 -2/问、红鱼 -8/次、提示 -15/次)+ 推理质量(触及关键要素数)。
- **提示**:`/hint` 三层苏格拉底式提示,只给方向不给答案。
- **技巧**:别在错误方向兜圈子(毒/钱/仇通常是红鱼);"味道""经历""同伴"是高频突破口。

### 4.2 侦探推理(`/game new detective [1-3]`)

- **目标**:锁定凶手,并写出一份完整的推理报告(凶手/手法/动机/证据链)。
- **玩法**:勘查地点(说"检查书房"即可)→ 审讯嫌疑人(说"问管家案发时在哪"即可,嫌疑人会按人设与说谎边界回应)→ 出示证据(说"把湖里捞起的火钳拿给管家看")→ 终局二选一:直接指控,或提交完整推理报告换取更高分。
- **专属命令**:`/casefile` 线索卷宗(含证词矛盾与泄密审计记录)。
- **计分**:结论正确性(凶手 60 + 手法 20 + 动机 20)+ 推理质量(独立评审逐条评)+ 效率。
- **技巧**:证人会撒谎但撒谎有边界——把证词与物证交叉比对;两条铁证齐备时,凶手会当场崩溃。

### 4.3 密室逃脱(`/game new escape [1-3]`)

- **目标**:解开全部机关,逃出密室;难度 1/2/3 = 2/3/4 个房间。
- **玩法**:用自然语言操作一切——"撬开窗户""用火柴点壁炉""把钟拨到四点半"。每个动作都由确定性引擎裁决:机关没满足前置就是没反应,GM 无法替你放水。谜底只在引擎里,暴力猜中会被审计并在结算注明。
- **专属命令**:`/look`(房间)`/bag`(背包)`/map`(房间解锁关系)。
- **计分**:结论正确性 + 推理质量(暴力猜谜扣分)+ 效率(计时与提示扣分)。
- **技巧**:机关的"前置条件"都在物品描述里;卡住时 `[hint]` 三层提示从方向到半解,绝不含答案。

### 4.4 剧本杀(`/game new party [1-3]`,难度 3 = 反转模式)

- **目标**:搜证、对质,找出 5 名 AI 角色中的真凶。
- **玩法**:搜证("搜书房")→ 私聊对质("单独问梅姨……")→ 公聊(抛出一条线索,引擎并发收集全场反应,每人一句)→ 出示铁证触发凶手崩溃 → 终局指控,双栏结算。
- **反转模式(难度 3)**:你是凶手。秘密凶手卡只有你自己能看(`/role`,主持人上下文里没有);每轮陈述由引擎对照证据裁决嫌疑度,5 轮质询后终局——全身而退或被识破。
- **专属命令**:`/roles` 名册、`/timeline` 已确证时间线、`/role` 我的角色卡。
- **计分**:推理正确性(投对/被投对)+ 扮演质量(独立评审)。

### 4.5 时间循环(`/game new loop [1-3]`)

- **目标**:每个循环 8 个时间片,19:00 悲剧必然降临;用跨循环积累的知识切断因果链,终局提交"完美一日"方案改写结局。
- **玩法**:每个时间片选一个行动(移动消耗 1 片)→ 观察谁在何时何地做什么 → 日末悲剧 → 世界回滚,但**元知识清单、NPC 好感度、道具认知、循环 diff 全部保留**。已确认无风险的动作可快进重放。
- **专属命令**:`/facts` 元知识、`/relations` 好感度、`/schedule` 已观测时间表、`/loops` 循环记录与 diff。
- **计分**:结论正确性(是否阻止悲剧)+ 推理质量 + 效率(循环数)。
- **技巧**:NPC 不知道自己在循环里——同一句话换个人、换个时间点问,答案会不一样。

### 4.6 王国议会(`/game new council [1-3]`)

- **目标**:经营王国 20 季,让它繁荣、维持或覆灭;同时练就识人本领。
- **玩法**:每季 = 事件揭示 → 四顾问发言(财政大臣/将军/大祭司/密探头子,各怀议程、知识质量不同、可能欺瞒,台词由隔离子代理撰写)→ 你用有限行动点追问/调查/遣使 → 拍板(支持自定义方案)→ 规则结算账本与信任评级。
- **专属命令**:`/ledger` 账本与隐藏祸患趋势、`/trust` 顾问信任评级、`/history` 历史决策。
- **计分**:王国结局(确定性)+ 决策质量(评审)+ 识人准确度。
- **技巧**:每局顾问的贪腐度/被收买者是随机的——先调查再信任;信任评级只是参考,高可信度顾问也可能翻脸。

### 4.7 单人跑团(`/game new trpg [1-3]`)

- **目标**:自由冒险:建卡 → 探索程序化世界 → 奇招/战斗/对话 → 主支线任务 → 成长与结局。跨会话战役。
- **玩法**:像真的跑团一样打字("我悄悄绕到守卫背后,把木桶套在他头上")。GM 只能**提议**裁决(难度 DC + 相关技能 + 后果),骰子由引擎掷出并留档——奇招被接住,数值不口胡。战斗是回合制状态机,失败不死档。
- **专属命令**:`/sheet` 角色卡、`/quests` 任务日志、`/world` 地图(`/bag` `/map` 亦可用)。
- **计分**:任务完成度 + 成长等级 + 效率。

## 5. 计分与结算

所有游戏终局都有**三栏结算卡**(剧本杀为双栏):结论正确性(引擎对真相精确比对)、推理质量(独立评审按锚定 rubric 打分)、效率(回合/提示/耗时/循环数)。`/game quit` 会直接展示完整真相与结算(该内容渲染在命令结果里,不进模型上下文,不影响后续会话)。

---

## 6. 存档与断线续玩

- 游戏状态**自动落盘**于 `$DSH_HOME/storages/dsh-xgame/<会话>/`(状态与真相分文件,权限 0600);关掉网页再回来,`/game resume` 续玩。
- 同一会话只能同时进行一局游戏;`/game quit` 结束并清除存档。
- 内容(汤底/案件/剧本/世界)按会话确定性选择——同一会话续局永远是同一局。

## 7. 常见问题(FAQ)

| 问题 | 解答 |
|---|---|
| 开局后 GM 报"llm 服务不可用" | DSH 没有可用 LLM(provider/model/key 未配好),回到 §2.3;插件需要宿主组合挂载 `@deepseek-ai/dsh-llm` |
| 主持人说"当前会话没有进行中的游戏" | 先 `/game new <类型>` 开局;或直接说"想玩 XX"让 GM 调用 game_start |
| NPC 突然"警觉地停住" | 这是泄密审计在起作用:该台词越过了它的知识边界,已被引擎作废——恰恰说明你问到了要害 |
| 想换一款游戏 | `/game quit` 结束当前对局,再 `/game new <类型>` |
| 升级插件 | 本地安装:`npm run build` 后重启 `dsh` 进程;npm 安装:`dsh plugin --profile game update dsh-xgame` 后重启 |
| 没有 subagent 服务的主机 | 插件自动回退插件侧 LLM 扮演 NPC,照常可玩 |
| 无头环境如何验证 | `dsh plugin --profile gamehead add dsh-xgame` 并把 bundles 换成 `@deepseek-ai/dsh-base` + `@deepseek-ai/dsh-headless` + `dsh-xgame`,然后 `dsh --profile gamehead "开始一局海龟汤,然后问第一个问题"` |
